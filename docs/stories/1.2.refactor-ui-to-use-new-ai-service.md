## Dev Notes

This story connects the new API client from Story 1.1 to the existing UI. The main change is in the `regenerateResponse` function in `AIAssistantContext.tsx`.

### Current Implementation Analysis

**File**: `src/app/features/ai-assistant/AIAssistantContext.tsx`

**Current `regenerateResponse` function (lines 118-150)**:

```typescript
const regenerateResponse = useCallback(
  async (spec = {}) => {
    setIsGeneratingResponse(true);
    deleteText();

    try {
      // Get the actual room conversation from timeline
      const timeline = room.getLiveTimeline().getEvents();
      const roomContext = timeline
        .filter((event) => event.getSender() && event.getContent().body)
        .map((event) => ({
          sender: event.getSender() as string,
          text: event.getContent().body as string,
          timestamp: new Date(event.getTs()).toISOString(),
          is_from_me: isFromMe(event.getSender() as string, mx.getUserId() as string),
        }));
      const lastNonUserMsg = [...roomContext].reverse().find((msg) => !msg.is_from_me);

      // Find the last message in the room conversation that is not from the current user
      const message = lastNonUserMsg ? lastNonUserMsg.text : 'Nói gì cũng được';

      const response = await generateResponseFromMessage({ message, context: roomContext, spec });
      setGeneratedResponse(response);
      handleUseSuggestion(response);
    } catch (error) {
      setGeneratedResponse('Xin lỗi, đã có lỗi');
    } finally {
      setIsGeneratingResponse(false);
      setInitialMessageGenerated(true);
    }
  },
  [room, mx, handleUseSuggestion, deleteText]
);
```

**What needs to change**:

1. Import the new API client function (from Story 1.1)
2. Construct the `spec` object from `selectedPersona` and `toneValues` state
3. Call the new API client function instead of old `generateResponseFromMessage`
4. Handle the new response format (`text` field instead of `response`)

**Spec object structure** (to be constructed):

```typescript
const spec = {
  persona: selectedPersona.id, // or full persona object
  tone: toneValues, // Record<string, number>
};
```

```typescript
const regenerateResponse = useCallback(
  async () => {
    // Remove spec parameter, build internally
    setIsGeneratingResponse(true);
    deleteText();

    try {
      // Get room context (existing code)
      const timeline = room.getLiveTimeline().getEvents();
      const roomContext = timeline
        .filter((event) => event.getSender() && event.getContent().body)
        .map((event) => ({
          sender: event.getSender() as string,
          text: event.getContent().body as string,
          timestamp: new Date(event.getTs()).toISOString(),
          is_from_me: isFromMe(event.getSender() as string, mx.getUserId() as string),
        }));

      const lastNonUserMsg = [...roomContext].reverse().find((msg) => !msg.is_from_me);
      const message = lastNonUserMsg ? lastNonUserMsg.text : 'Nói gì cũng được';

      // Build spec from state
      const spec = {
        persona: selectedPersona,
        tone: toneValues,
      };

      // Call NEW API client
      const response = await generateResponseFromNewBackend({
        message,
        context: roomContext,
        spec,
      });

      setGeneratedResponse(response);
      handleUseSuggestion(response);
    } catch (error) {
      setGeneratedResponse('Xin lỗi, đã có lỗi');
      console.error('Error generating response:', error);
    } finally {
      setIsGeneratingResponse(false);
      setInitialMessageGenerated(true);
    }
  },
  [room, mx, handleUseSuggestion, deleteText, selectedPersona, toneValues] // Add dependencies
);
```
