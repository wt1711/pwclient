## Dev Notes

This story migrates the `regenerateResponse()` function from the Promise-based fetch API to the callback-based EventSource SSE API. The key change is replacing a single response with incremental chunk updates that create a real-time streaming effect.

#### SSE Client Integration Pattern

[Source: Story 2.1 Dev Notes - SSE Client Implementation Pattern]

**SSE Function Signature**:

```typescript
export function generateResponseFromMessageSSE({
  message,
  context,
  spec,
  onChunk,
  onError,
  onComplete,
}: GenerateResponseSSEParams & GenerateResponseSSECallbacks): SSEAbortFunction;
```

**Callback-Based Pattern**:

- `onChunk(chunk: string)` - Called for each text chunk
- `onError(error: Error)` - Called on stream error
- `onComplete()` - Called when stream finishes
- Returns abort function `() => void` for cleanup

#### Recommended Implementation Pattern

[Source: architecture/frontend-architecture.md#state-management]

**State Update Pattern for Streaming**:

```typescript
const regenerateResponse = useCallback(async () => {
  // Cancel any existing stream
  if (abortStreamRef.current) {
    abortStreamRef.current();
  }

  // Reset state
  setIsGeneratingResponse(true);
  setGeneratedResponse(''); // Clear previous response
  deleteText();

  try {
    // Get room conversation context (same as current)
    const timeline = room.getLiveTimeline().getEvents();
    const roomContext = timeline
      .filter((event) => event.getSender() && event.getContent().body)
      .map((event) => ({
        sender: event.getSender() as string,
        text: event.getContent().body as string,
        timestamp: new Date(event.getTs()).toISOString(),
        is_from_me: isFromMe(event.getSender() as string, mx.getUserId() as string),
      }));
    const lastNonUserMsg = [...roomContext].reverse().find((msg) => !msg.is_from_me);
    const message = lastNonUserMsg ? lastNonUserMsg.text : 'Nói gì cũng được';

    // Build spec object (same as current)
    const spec = {
      persona: selectedPersona,
      tone: toneValues,
    };

    // Call SSE API client with callbacks
    const abort = generateResponseFromMessageSSE({
      message,
      context: roomContext,
      spec,
      onChunk: (chunk: string) => {
        // Append chunk to state - functional update to avoid stale closure
        setGeneratedResponse((prev) => prev + chunk);
      },
      onError: (error: Error) => {
        console.error('Stream error:', error);
        setGeneratedResponse('Xin lỗi, đã có lỗi');
        setIsGeneratingResponse(false);
      },
      onComplete: () => {
        setIsGeneratingResponse(false);
        setInitialMessageGenerated(true);
        // Note: handleUseSuggestion is called via effect watching generatedResponse
      },
    });

    // Store abort function for cleanup
    abortStreamRef.current = abort;
  } catch (error) {
    console.error('Error starting stream:', error);
    setGeneratedResponse('Xin lỗi, đã có lỗi');
    setIsGeneratingResponse(false);
    setInitialMessageGenerated(true);
  }
}, [room, mx, deleteText, selectedPersona, toneValues]);
```

**Cleanup Pattern**:

```typescript
// Add ref to component
const abortStreamRef = useRef<(() => void) | null>(null);

// Cleanup on unmount
useEffect(() => {
  return () => {
    if (abortStreamRef.current) {
      abortStreamRef.current();
    }
  };
}, []);
```

#### State Management Considerations

[Source: architecture/frontend-architecture.md#state-management]

**Functional State Updates**:

- Use functional update pattern `setState((prev) => ...)` to avoid stale closures
- Each chunk appends to previous state without re-reading from closure

**Ref for Cleanup**:

- Use `useRef` to store abort function (not state, as it doesn't need to trigger re-renders)
- Ref persists across re-renders and is accessible in cleanup

**Side Effect Management**:

- `handleUseSuggestion()` may need to be triggered differently
- Consider using `useEffect` to watch `generatedResponse` and call `handleUseSuggestion()` when complete
- Alternative: Call `handleUseSuggestion()` in `onComplete` callback

#### Handling `handleUseSuggestion` Integration

**Current Pattern**: `handleUseSuggestion(response)` is called after response is set

**Challenge**: With streaming, we don't have the full response until complete

**Solution Options**:

1. **Option A: Call in onComplete with state** (Recommended)

   ```typescript
   onComplete: () => {
     setIsGeneratingResponse(false);
     setInitialMessageGenerated(true);
     // Note: generatedResponse state will be updated by this point
   };
   ```

   Then add `useEffect` to watch `generatedResponse`:

   ```typescript
   useEffect(() => {
     if (generatedResponse && !isGeneratingResponse && initialMessageGenerated) {
       handleUseSuggestion(generatedResponse);
     }
   }, [generatedResponse, isGeneratingResponse, initialMessageGenerated]);
   ```

2. **Option B: Use ref to track final response**

   ```typescript
   const finalResponseRef = useRef('');

   onChunk: (chunk) => {
     finalResponseRef.current += chunk;
     setGeneratedResponse((prev) => prev + chunk);
   };

   onComplete: () => {
     handleUseSuggestion(finalResponseRef.current);
     finalResponseRef.current = '';
     setIsGeneratingResponse(false);
   };
   ```

**Recommendation**: Use Option A to leverage React's state management and avoid duplicate state tracking.

// AIAssistantContext.test.tsx
describe('regenerateResponse with SSE', () => {
  it('should stream chunks and append to state', async () => {
    const mockAbort = vi.fn();
    let capturedCallbacks: any;

    (aiUtils.generateResponseFromMessageSSE as Mock).mockImplementation((params) => {
      capturedCallbacks = params;
      return mockAbort;

    act(() => {
      result.current.regenerateResponse();

    // Simulate streaming
    act(() => {
      capturedCallbacks.onChunk('Hello');
    });
    expect(result.current.generatedResponse).toBe('Hello');

    act(() => {
      capturedCallbacks.onChunk(' world');
    });
    expect(result.current.generatedResponse).toBe('Hello world');

    act(() => {
      capturedCallbacks.onComplete();
    });
    expect(result.current.isGeneratingResponse).toBe(false);

      <AIAssistantProvider isMobile={false}>{children}</AIAssistantProvider>
    );

    const { result } = renderHook(() => useAIAssistant(), { wrapper });

    // First generation
    act(() => {
      result.current.regenerateResponse();
    });

    // Second generation should abort first
    act(() => {
      result.current.regenerateResponse();
    });

    expect(mockAbort1).toHaveBeenCalled();
  });

  it('should handle stream errors', async () => {
    let capturedCallbacks: any;

      return vi.fn();
    });

    const wrapper = ({ children }: { children: React.ReactNode }) => (
      <AIAssistantProvider isMobile={false}>{children}</AIAssistantProvider>
    );

    const { result } = renderHook(() => useAIAssistant(), { wrapper });

    act(() => {
      result.current.regenerateResponse();
    });

    // Simulate error
    act(() => {
      capturedCallbacks.onError(new Error('Stream failed'));
    });
