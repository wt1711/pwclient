## Status

## Story

**As a** user,
**I want** to see the AI-generated response text displayed in real-time as it streams,
**so that** I get immediate visual feedback that the AI is generating my response.

## Acceptance Criteria

1. GeneratedResponseBox component displays the streaming response text from AIAssistantContext
2. Component shows a spinner/loading indicator when `isGeneratingResponse` is true
3. Component displays the accumulated `generatedResponse` text as it streams in
4. The response text updates in real-time with each chunk (typing effect)
5. Error messages continue to be displayed when `errorMessage` is set
6. Component uses only props/state from AIAssistantContext (no local streaming logic)
7. The UI maintains existing look and feel with Folds components and design tokens
8. Response text is clearly visible and properly formatted

Story 3.2 successfully refactored AIAssistantContext to use the streaming service from Story 3.1. The context now provides clean streaming state for UI consumption:

**Streaming State in Context:**

- `isGeneratingResponse: boolean` - Indicates if stream is active
- `generatedResponse: string` - Accumulated response text (updates with each chunk)
- `errorMessage: string | null` - User-friendly error message

**State Flow:**

1. User triggers `regenerateResponse()` → `isGeneratingResponse` set to `true`, `generatedResponse` reset to `''`
2. Chunks arrive → `generatedResponse` updates via `setGeneratedResponse(prev => prev + chunk)`
3. On completion → `isGeneratingResponse` set to `false`
4. On error → `errorMessage` set, `isGeneratingResponse` set to `false`

**Key Pattern from Story 3.2:**
Functional state updates (`setGeneratedResponse(prev => prev + chunk)`) ensure the UI automatically re-renders with each chunk, creating the real-time typing effect.

### Real-Time Rendering Behavior

[Source: Story 2.2, AIAssistantContext.tsx]

**Automatic Re-rendering:**

When chunks arrive from the streaming service:

1. Context updates: `setGeneratedResponse(prev => prev + chunk)`
2. Context state changes trigger re-render of all consumers
3. GeneratedResponseBox re-renders with new `generatedResponse` value
4. Text component displays updated text
5. User sees "typing effect" as text grows

**No Special Logic Required:**

React's reactivity handles the real-time updates automatically. The component just needs to:

- Subscribe to context via `useAIAssistant()`
- Render `{generatedResponse}` in JSX
- React will re-render when `generatedResponse` changes

### State Combinations to Handle

[Source: Architecture - Frontend Architecture]

| isGeneratingResponse | generatedResponse | errorMessage | UI State                                      |
| -------------------- | ----------------- | ------------ | --------------------------------------------- |
| `false`              | `''`              | `null`       | Default: Show controls only                   |
| `true`               | `''`              | `null`       | Loading: Show spinner + controls              |
| `true`               | `'text...'`       | `null`       | Streaming: Show spinner + text + controls     |
| `false`              | `'text...'`       | `null`       | Complete: Show text + controls                |
| `false`              | `''`/`'text...'`  | `'error'`    | Error: Show error message + controls (+ text) |

**Conditional Rendering Logic:**

```typescript

{generatedResponse && <ResponseTextBox />}
<Slider />
<ToneSelector />
<PersonaSelector />
```

All conditions can coexist (e.g., streaming with partial text shows both spinner and text).
