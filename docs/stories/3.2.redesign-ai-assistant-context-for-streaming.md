### State Management Patterns

[Source: Architecture - Frontend Architecture, AIAssistantContext.tsx]

**React Context Pattern:**

The AIAssistantContext follows the standard React Context pattern:

- `createContext` for context creation
- Provider component wraps children
- Custom hook `useAIAssistant()` for accessing context
- State managed with `useState` hooks
- Actions wrapped in `useCallback` for stable references

**Streaming State:**

The context manages three key pieces of streaming state:

1. `isGeneratingResponse: boolean` - Indicates if stream is active
2. `generatedResponse: string` - Accumulated response text
3. `errorMessage: string | null` - User-facing error message

**State Flow:**

1. User triggers `regenerateResponse()`
2. State reset: `setIsGeneratingResponse(true)`, `setGeneratedResponse('')`, `setErrorMessage(null)`
3. Stream starts via service
4. Chunks arrive: `setGeneratedResponse(prev => prev + chunk)`
5. On completion: `setIsGeneratingResponse(false)`
6. On error: `setErrorMessage(userMessage)`, `setIsGeneratingResponse(false)`

**Auto-trigger Pattern (Lines 140-144):**

```typescript
useEffect(() => {
  if (generatedResponse && !isGeneratingResponse && initialMessageGenerated) {
    handleUseSuggestion(generatedResponse);
  }
}, [generatedResponse, isGeneratingResponse, initialMessageGenerated, handleUseSuggestion]);
```

This effect automatically calls `handleUseSuggestion` when:

- Response is complete (`generatedResponse` exists)
- Stream has finished (`!isGeneratingResponse`)
- Initial message was generated (`initialMessageGenerated`)
